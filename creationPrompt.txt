# Role & Project Context
You are an expert Rust developer working on a robust TUI (Terminal User Interface) application called `bank_tui` built with `ratatui`. The application parses bank expenditure CSV files, handles categorization rules, filters ignored payees, performs precise duplicate detection, and supports Vim-style navigation.

# Key Technical Specifications & Implemented Features

## 1. Robust & Dynamic CSV Loading (`load_transactions_from_folder`)
- **Encoding Compatibility:** Automatically opens and reads CSV files using `String::from_utf8_lossy` to ensure seamless handling of both UTF-8 and legacy Windows-1252 / ISO-8859-1 encodings (preventing crashes on German umlauts).
- **Dynamic Header Detection:** Instead of relying on a hardcoded line skip, the parser dynamically scans file lines (ignoring BOMs like `\u{feff}`) to find the exact header line containing the keyword `"buchung"` (case-insensitive).
- **Flexible Column Mapping:** Uses keyword-based lookups (`find_col`) on the CSV headers to dynamically map column indices for:
  - `Buchung` (booking date)
  - `Wertstellung` (value date)
  - `Auftraggeber / Empfänger` (payee)
  - `Buchungstext` (booking text)
  - `Verwendungszweck` (purpose / handles missing/empty fields gracefully)
  - `Betrag` (amount)
  - `Währung` (currency)
- **Flexible CSV Reader:** Built using `csv::ReaderBuilder` with semicolon delimiter (`b';'`), headers enabled, and `flexible(true)` to handle variable column counts (e.g., when banks add or remove optional columns over time).

## 2. Validation & Precision Logging
Every skipped or unadded entry is logged precisely to `stderr` with detailed rejection reasons and raw line outputs:
- **Missing Mandatory Fields:** Skips lines where `Buchung` or `Betrag` is empty.
- **Column Mismatch / Parsing Errors:** Catches CSV parsing errors and logs them.
- **Duplicate Detection:** Uses a `HashMap` based on a unique transaction key (`buchung|payee|text|purpose|amount|currency`) to detect exact duplicates, printing both the original line and the duplicate line.
- **Ignored Payees:** Checks payee names against a case-insensitive `ignore_payees` list configured in `config.toml`.
- **Amount & Income Filtering:** Parses German amounts (e.g., via `parse_german_amount`), strictly ignoring positive amounts or zero (keeping expenditures only).
- **Date Parsing:** Validates and parses booking dates using the `%d.%m.%Y` format.

## 3. Code Quality & Maintenance
- Clean Rust imports (proper scoping of `std::io::{Read, BufReader}`, avoiding duplicate or unused imports).
- Designed to be compiled in release mode (`cargo build --release`) and placed in user binary directories like `~/.local/bin/` for global terminal execution.
